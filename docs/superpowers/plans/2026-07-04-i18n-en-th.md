# EN/TH Language Switching Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users toggle the PixelPay web app between English and Thai via a cookie-persisted switcher, covering every hardcoded UI string including the admin panel.

**Architecture:** `next-intl` in "without i18n routing" mode. A `pixelpay-locale` cookie (default `en`) is read by `getRequestConfig` on the server; the root layout provides messages to client components via `NextIntlClientProvider`. A server action sets the cookie and the switcher calls `router.refresh()` so server + client components re-render in the new language.

**Tech Stack:** Next.js 14.2 App Router, next-intl ^3.26, react-hook-form + zod, Tailwind.

**Spec:** `docs/superpowers/specs/2026-07-03-i18n-en-th-design.md`

## Global Constraints

- Default locale is `en`; the only other locale is `th`. Cookie name: `pixelpay-locale`, max-age 1 year.
- URLs never change — no `/en/...` prefixes, no changes to `middleware.ts` route matching.
- Dynamic API content (game names, product names, descriptions) is NOT translated.
- Number/date formatting stays exactly as-is (`toLocaleString('th-TH')` everywhere).
- The Thai brand tagline `เติมเกมไว ปลอดภัย คุ้มค่า` and the promise `<dt>` words (`เติมเกมไว`, `ปลอดภัย`, `คุ้มค่า`) are brand elements — they stay Thai in BOTH locales. `metadata` in `app/layout.tsx` stays untouched.
- **Never run `next build` on the host while the docker stack is running** (`.next` is volume-mounted). Verify with `npx tsc --noEmit` and the dev server at http://localhost:4001.
- The web container has its own `node_modules` (anonymous volume). After changing `package.json`, run `docker compose up -d --build web`. If the stack isn't running, host-only verification (`tsc`) is fine.
- Design system: dark arcade theme (`void`/`frost`/`pixel`/`neon` tokens, `pixel-cut` clip corners, `font-display`/`font-body`/`font-mono`). New UI (LanguageSwitcher, Pagination) must use these tokens, not generic Tailwind colors.
- Message files live at `apps/web/messages/en.json` and `apps/web/messages/th.json`. English is source of truth; both files must have identical key sets (enforced by `npm run check-messages`).
- Every commit: run `cd apps/web && npx tsc --noEmit && npm run check-messages` first. Commit with `git -c user.name='iPOND' -c user.email='75074564+idogpond@users.noreply.github.com' commit ...` if git identity is not configured.
- All paths below are relative to `apps/web/` unless they start with `docs/` or `apps/`.

Create `apps/web/scripts/check-messages.mjs`:

```js
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';

const root = join(dirname(fileURLToPath(import.meta.url)), '..');
const load = (l) => JSON.parse(readFileSync(join(root, 'messages', `${l}.json`), 'utf8'));

const keys = (obj, prefix = '') =>
  Object.entries(obj).flatMap(([k, v]) =>
    typeof v === 'object' && v !== null ? keys(v, `${prefix}${k}.`) : [`${prefix}${k}`],
  );

const en = new Set(keys(load('en')));
const th = new Set(keys(load('th')));
const missingInTh = [...en].filter((k) => !th.has(k));
const missingInEn = [...th].filter((k) => !en.has(k));

if (missingInTh.length || missingInEn.length) {
  if (missingInTh.length) console.error('Missing in th.json:', missingInTh);
  if (missingInEn.length) console.error('Missing in en.json:', missingInEn);
  process.exit(1);
}
console.log(`OK — ${en.size} keys in both catalogs`);
```

Add to `apps/web/package.json` scripts: `"check-messages": "node scripts/check-messages.mjs"`.

import { useTransition } from 'react';
import { useLocale } from 'next-intl';
import { useRouter } from 'next/navigation';
import { setLocale, Locale } from '../../app/actions/locale';

export function LanguageSwitcher() {
  const locale = useLocale();
  const router = useRouter();
  const [isPending, startTransition] = useTransition();

  const switchTo = (next: Locale) => {
    if (next === locale) return;
    startTransition(async () => {
      await setLocale(next);
      router.refresh();
    });
  };

  return (
    <div
      role="group"
      aria-label="Language"
      className="flex items-center border border-frost/20 font-mono text-xs pixel-cut"
    >
      {(['en', 'th'] as const).map((l) => (
        <button
          key={l}
          type="button"
          onClick={() => switchTo(l)}
          disabled={isPending}
          aria-pressed={l === locale}
          className={
            l === locale
              ? 'px-2 py-1 bg-pixel/20 text-pixel-bright font-bold'
              : 'px-2 py-1 text-frost/50 hover:text-frost transition-colors'
